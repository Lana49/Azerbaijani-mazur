Лабораторная работа №2. Системы контроля версий

В ходе лабораторной работы была изучена распределённая система контроля версий Git.
Для хранения удалённого репозитория использовался облачный сервис GitHub.
Репозиторий был создан на GitHub, после чего выполнено его клонирование на локальный компьютер.
В процессе работы были освоены основные команды Git: status, add, commit, push и pull.
Также была изучена работа с ветками, позволяющая выполнять изменения отдельно от основной ветки main.
Для объединения изменений использовался механизм Pull Request.
В рамках совместной работы было выполнено ревью изменений и последующее слияние веток.

Дополнение к отчёту:
1. Была создана отдельная ветка для внесения изменений в отчёт.
2. Изменения были зафиксированы с помощью commit и отправлены на GitHub командой push.
3. Для добавления изменений в основную ветку был создан Pull Request и проведено code review.
